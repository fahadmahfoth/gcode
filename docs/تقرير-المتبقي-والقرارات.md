## ثانياً — الأمور غير المكتملة

### الطور 0 — أساس المستودع (🟡)

- **0.8** صار بوابة CI محلية: `scripts/ci.sh` (fmt، clippy، اختبارات، فحوصات
  السياسة، الأسرار، الروابط). تعمل خضراء على macOS aarch64.
- **0.12** القوالب وفحص الأسرار: الفحص انتقل إلى `scripts/ci.sh`، والقوالب
  باقية تحت `.github/` (ليست Actions).
- **معيار:** بناء `cargo build --release` مُعلَّق الآن **عمدًا** لأن مدخلات سجل
  النماذج `verified = false` (ADR 0018)؛ يلزم تنزيل النموذج وبصمته مرة.
- **معيار:** البوابة المحلية تخرج بصفر — ✅ على macOS aarch64، و✅ على Linux
  x86_64 (2026-10-03: 0 إخفاق، تخطٍّ واحد هو بناء الإصدار المرفوض عمدًا).

**سبب تغيير المسار:** حساب GitHub مقفل لأسباب فواتير، فتوقف العمل عن GitHub
Actions بالكامل ([ADR 0019](adr/0019-local-ci-not-github-actions.md)).

**ما يُنهي هذا الطور:** توثيق نموذج واحد بتنزيل فعلي ثم `verified = true`
فيُقبل بناء الإصدار. (منفّذ Linux الدائم يبقى اختياريًا.)

### الطور 1 — خط الاستدلال الأساسي (🟡)

- **1.1–1.4، 1.7، 1.8:** مكتملة ومختبرة.
- **1.5 — أداة أخذ العينات (sampler):** الناقص هو `LlamaEngine::load`
  (تحميل mmap + تسخين) والتوقف عند EOG/السطر الجديد/`max_tokens`. الباقي
  (السمة، ما بعد المعالجة، المهلة) مكتمل ومختبر ضد `FakeEngine`.
  **محجوب:** يحتاج `llama-cpp-rs` وسلسلة أدوات C++ وأوزان نموذج حقيقية.
- **1.6 — قيود القواعد (grammar):** لم يبدأ، ويعتمد على 1.5. نقل قواعد EBNF
  لـ bash، منع fork bomb، دمج `llguidance`، اختبارات ولقطات (snapshots).
- **معايير قبول معلّقة:** `gcode -c "..." --dry-run` يُنتج أمرًا؛ 10/10 أوامر
  صالحة؛ زمن p50 < 1000ms؛ القواعد تمنع صدفة غير صالحة.
- **نقص في 1.4:** لا نقل HTTPS، ميزة التنزيل غير موصولة، لا عارض تقدّم على
  `stderr`، ولا شيء ينادي `ensure_model()` بعد.
- **سجل النماذج:** استُبدل العنصر المبدئي (placeholder) بثلاثة نماذج حقيقية
  مثبّتة على commit — `qwen3-0.6b` افتراضيًا (متعدد اللغات: عربي + إنجليزي)،
  و`kitty-bash-llm` (إنجليزي فقط)، و`qwen3-1.7b` — مع أحجام وروابط وبصمات.
  لكنها كلها `verified = false` لأن البصمات منشورة من HuggingFace ولم
  تُتحقَّق محليًا بتنزيل فعلي. `build.rs` يرفض بناء الإصدار ما دام أي عنصر غير
  موثّق (لذلك بناء `--release --locked` **يفشل عمدًا**). التفاصيل في
  [ADR 0018](adr/0018-bilingual-default-model.md).

**ما يُنهي هذا الطور:** تنزيل النموذج وحساب بصمته فعليًا ثم `verified = true`،
ومساحة قرص كافية، ثم كتابة أداة أخذ العينات والقواعد.

### الطور 2 — تكامل الصدفة والسجل (🟢)

- **2.1–2.6** منفّذة ومختبرة بالكامل (سجل JSONL، سياق البيئة، خطّافا bash و
  zsh، المثبِّت، `--fix`، `--complete`).
- **معيار قبول معلّق:** `gcode --init` → أمر فاشل → `gcode --fix` يصحّحه
  فعليًا — **يحتاج النموذج الحقيقي (1.5)**.
- **معيار قبول معلّق:** التأكد من العمل في bash و zsh — يُنفَّذ محليًا عبر
  `scripts/ci.sh`؛ لا سير عمل GitHub بعد الآن.

### الطور 3 — طبقة الأمان (🟡)

- **3.6 — تقدير كلفة MEDIUM+:** المفتوح الوحيد؛ يحتاج النموذج، ووحدة الكلفة
  لم تُعرَّف بعد.
- حُسمت سابقًا: Ctrl+C بلا معالج ([ADR 0022](adr/0022-no-signal-handler.md))،
  ومفتاح النسخ `c` عبر أداة النظام ([ADR 0020](adr/0020-clipboard-via-platform-tool.md)).
- **أُصلح في هذه الجولة:** قائمة الحظر `safety.blocklist` صارت تُطبَّق فعلاً
  (كانت تُقرأ ولا تصل إلى المصنِّف)، وخطأ ملف الإعدادات صار يوقف البرنامج.

### الططور 4–6 — (⬜ لم تبدأ)

## ثالثاً — الأمور التي تستوجب قرارك أنت

مرتّبة من الأكثر إلحاحًا إلى الأقل:

### قرارات تحجب العمل فعليًا

1. **حساب GitHub مقفل (فواتير) 🔒** — لم يعد يحجب المشروع: توقّفنا عن
   GitHub Actions واستبدلناها بـ `scripts/ci.sh` ([ADR 0019](adr/0019-local-ci-not-github-actions.md)).
   يبقى قرارك فقط إن أردت العودة إلى الاستضافة لاحقًا (أو منفّذًا مستضافًا
   ذاتيًا لبناء Linux).
2. **النموذج الحقيقي 🔒** — أُضيفت ثلاثة نماذج حقيقية مثبّتة على commit في
   `models/registry.toml`، لكن بصماتها منشورة من HuggingFace ولم تُتحقَّق
   بتنزيل محلي. المطلوب منك: مساحة قرص، ثم تشغيل التنزيل و`verified = true`.
   (ADR 0010 يمنع اعتبار بصمة غير مُتحقَّقة موثوقة؛ ADR 0018 يختار الافتراضي.)
3. **مساحة القرص** — الحرة الآن ≈ **2.3 GiB فقط** على قرص ممتلئ 99%.
   بناء C++ مع بضع GiB من الأوزان لن يتّسع. المطلوب: تحرير **15–20 GiB**
   قبل 1.5.

### قرارات تصميم مفتوحة

4. ~~**تأكيد أو رفض ربط `--generate` عبر `build_prompt`**~~ — **أُقرّ (نعم
   اسمح)**: تمرير الطلب عبر التنقيح قبل النموذج، لسدّ ثغرة ADR 0006، وبقي كما هو.
5. ~~**الفرع المعتمد: `main` أم `master`؟**~~ — **عُقد القرار: `main` هو
   المعتمد**. سيُعاد توجيه `main` ليطابق `master` (يحمل العمل الحقيقي) ثم
   يُصحَّح نص `CONTRIBUTING.md` ورابط `origin/HEAD` لاحقًا.
6. ~~**`panic = "abort"` مقابل `unwind`**~~ — **لا تعارض**: ADR 0002 البند 4
   ينصّ على `abort` في الإصدار، وهو ما يضبطه `Cargo.toml`.
7. ~~**Ctrl+C**~~ — **محسوم** في ADR 0022 (سلوك العملية الافتراضي، بلا معالج).
8. ~~**الحافظة (`c`)**~~ — **محسوم** في ADR 0020 (أداة نظام، بلا تبعية).
9. ~~**قيد إصدار `clap` وخط MSRV**~~ — **أُغلق**: `clap` مقيّد بـ `>=4.5, <4.6`،
   و`clap_lex` و`indexmap` مقيّدان في `Cargo.toml`، و`cargo update` لم يعد
   يرفعها (تحقّقت بـ `cargo update --dry-run`).
10. ~~**`indexmap`**~~ — أُغلق مع البند 9.
11. **تقدير كلفة MEDIUM+** — بعد توفّر النموذج، يجب تعريف وحدة الكلفة
    كيفًا ومقدارًا.

### قرارات جديدة من هذه الجولة

- **شبكة البيئة 🔒:** `huggingface.co` محجوب بسياسة الشبكة، فلا يمكن تنزيل
  النموذج وتوثيق البصمات هنا. أضِفه تحت Allowed domains في إعدادات البيئة
  (Network access ← Custom) إن أردت أن أُكمل 1.4 و1.5. تعليق: بدون هذا لا يمكن
  رفع `verified = true` ولا بناء `--release`.
- **تراخيص خارج قائمة ADR 0009:** `deny.toml` يسمح بـ `MPL-2.0` (لـ
  `option-ext` عبر `dirs`) و`CDLA-Permissive-2.0` (لـ `webpki-roots` عبر
  `ureq`)، وهما موجودان أصلًا في الشجرة. أحتاج منك إقرارهما بتعديل ADR جديد،
  أو استبدال التبعية.
- **تبعية `llama-cpp-2` (1.5):** تبعية طرف ثالث جديدة بسلسلة C++، وتحتاج
  موافقتك قبل إضافتها، وتحقّقًا من ترخيصها وخط MSRV.
- **المنفّذ (`exec/runner.rs`):** غير مدرج في ROADMAP رغم وروده في
  ARCHITECTURE. أقترح إدراجه مهمةً صريحة قبل تنفيذه.

### قرارات لاحقة (مؤجّلة عن قصد)

12. حسابات ومفاتيح النشر 🔒: حساب AUR، مستودع Homebrew (tap)، مشروع COPR،
    مفتاح APT GPG (عهدة المشرف)، نطاق `get.gcode.dev`، وحسابات النشر
    العلني. لا حاجة لأي منها الآن؛ أُدرجت كي لا تفاجئك لاحقًا.

## رابعاً — ما لا يمكن حسمه تقنيًا (معلوم ومقصود)

- `cargo build --release --locked` يفشل **بالتصميم** لأن مدخلات سجل النماذج
  `verified = false` ([ADR 0018](adr/0018-bilingual-default-model.md))؛ يزول
  الفشل بتوثيق النموذج بتنزيل فعلي واحد.
- لا سير عمل GitHub Actions في المستودع بعد الآن ([ADR 0019](adr/0019-local-ci-not-github-actions.md));
  البوابة هي `scripts/ci.sh`.
- التقاط مخرجات الأوامر عبر PTY يحتاج ADR جديدًا وتفويضًا صريحًا منك.
- لا يُلتزم أي تغيير في git إلا بأمر صريح منك.
